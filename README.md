# 🔐 Network Security Risk Assessment Lab

## 📖 Overview

This project demonstrates practical cybersecurity skills through a hands-on security assessment performed in a virtual lab environment using Kali Linux and Windows.

The assessment included network scanning, packet analysis, vulnerability assessment, and intrusion detection using industry-standard security tools.

---

## 🎯 Objectives

- Discover live hosts on the network
- Identify open ports and running services
- Analyse captured network traffic
- Identify security vulnerabilities
- Detect suspicious network activity
- Recommend security improvements

---

## 🛠️ Tools Used

- Kali Linux
- Windows 10
- Nmap
- Wireshark
- Metasploit Framework
- Snort IDS

---

## 💻 Practical Activities

### 1. Network Scanning
Performed host discovery and port scanning using **Nmap** to identify running services and potential risks.

### 2. Packet Analysis
Captured and analysed network traffic using **Wireshark** to identify protocols, plaintext communication, and suspicious activity.

### 3. Vulnerability Assessment
Used the Metasploit Framework to identify and investigate known vulnerabilities. Reviewed CVE information, assessed vulnerability severity, and recommended appropriate remediation measures.

### 4. Intrusion Detection
Used **Snort IDS** to detect simulated reconnaissance activity and analyse intrusion alerts.

## ⚠️ Key Security Findings

- Open ports increase the attack surface.
- HTTP traffic can expose sensitive information when not encrypted.
- Critical vulnerabilities should be prioritised based on severity.
- Intrusion Detection Systems help detect reconnaissance and malicious activity.
- Strong authentication and secure configurations significantly reduce security risks.
